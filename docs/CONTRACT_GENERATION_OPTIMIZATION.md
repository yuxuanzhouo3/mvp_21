# 企业合同生成优化方案

## 核心功能设计

### 1. 智能问答式合同生成（解决核心痛点）

#### 场景：HR需要给新员工生成入职合同

**流程设计：**

```
第一步：选择合同类型
├─ 劳动合同（正式员工）
├─ 劳务协议（实习生/兼职）
├─ 保密协议
└─ 其他...

第二步：企业信息收集（一次配置，永久使用）
问题1：公司全称？
问题2：统一社会信用代码？
问题3：法定代表人？
问题4：注册地址？
问题5：联系方式？
问题6：公司简介（主营业务）？

第三步：岗位信息收集
问题7：岗位名称？
问题8：工作地点？
问题9：部门？
问题10：直属上级？

第四步：薪资福利
问题11：基本工资？
问题12：绩效/奖金制度？
问题13：社保公积金？
问题14：其他福利？

第五步：工作时间
问题15：工作时间制度（标准工时/综合工时/不定时）？
问题16：试用期（1-6个月）？

第六步：其他条款
问题17：竞业限制？
问题18：培训协议？
问题19：特殊约定？

→ AI生成专业合同
```

### 2. PDF上传 + 智能识别

#### 功能流程：

```
用户上传PDF模板
    ↓
OCR识别文字
    ↓
AI分析合同结构
    ↓
提取可编辑字段：
    - 甲方信息: {{companyName}}
    - 乙方信息: {{employeeName}}
    - 薪资: {{salary}}
    - 日期: {{startDate}}
    ↓
生成可编辑模板
    ↓
用户只需填写变量
    ↓
一键生成新合同
```

### 3. 企业信息管理

**数据库设计：**

```sql
company_profiles (企业档案表)
- id
- user_id
- company_name          -- 公司全称
- credit_code           -- 统一社会信用代码
- legal_representative  -- 法定代表人
- registered_address    -- 注册地址
- contact_phone         -- 联系电话
- business_scope        -- 业务范围
- company_intro         -- 公司简介
- created_at
- updated_at

contract_variables (合同变量库)
- id
- company_id
- variable_name         -- 变量名 如: {{baseSalary}}
- variable_value        -- 变量值
- variable_category     -- 分类: 薪资/福利/时间等
- created_at
```

## 用户体验优化

### 场景1：HR第一次使用
```
进入系统 
  → 引导配置企业信息（5分钟）
  → 选择"劳动合同"
  → 回答10个问题（2分钟）
  → 自动生成专业合同
  → 预览 → 发送签署
```

### 场景2：HR已配置企业信息
```
选择"劳动合同"
  → 企业信息自动填充
  → 只需填写员工信息（姓名、岗位、薪资）
  → 30秒生成合同
```

### 场景3：企业有自己的模板
```
上传公司PDF模板
  → AI识别可变字段
  → 保存为企业专属模板
  → 下次只需填写变量
  → 一键生成
```

## 数据收集 - 生成专业劳动合同需要的信息

### 甲方（企业）信息
1. 公司全称
2. 统一社会信用代码
3. 法定代表人
4. 注册地址
5. 联系电话
6. 经办人姓名

### 乙方（员工）信息
7. 员工姓名
8. 身份证号码
9. 联系电话
10. 通讯地址

### 工作信息
11. 岗位名称
12. 工作地点
13. 所属部门
14. 岗位职责描述

### 合同期限
15. 合同起始日期
16. 合同类型（固定期限/无固定期限/项目制）
17. 合同期限（如：3年）
18. 试用期（1-6个月）

### 薪资待遇
19. 基本工资
20. 绩效工资/奖金制度
21. 社保公积金缴纳基数
22. 发薪日
23. 其他补贴（餐补、交通补贴等）

### 工作时间
24. 工作时间制度（标准工时/综合工时/不定时）
25. 每日/每周工作时间
26. 休息休假制度

### 特殊条款
27. 是否有竞业限制
28. 竞业限制期限和补偿
29. 是否有培训服务期约定
30. 是否有保密协议
31. 违约责任约定

## 竞品分析总结

### e签宝的核心优势：
1. ✅ 模板丰富且专业
2. ✅ 上传自定义模板方便
3. ✅ 字段标记清晰
4. ✅ 批量操作高效
5. ✅ 法律效力保障（CA认证）

### ContractHub的差异化优势：
1. ✅ AI智能问答生成（e签宝没有）
2. ✅ 跨境合同支持
3. ✅ 多语言生成
4. ✅ 对话式交互更友好
5. ✅ 适合中小企业（简单易用）
