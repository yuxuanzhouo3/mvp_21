## 🎨 界面设计理念

### 1️⃣ **一目了然**
- 左侧：3种创建方式，大卡片设计，图标+文字
- 中间：当前操作区域，沉浸式体验
- 右侧：实时反馈，所见即所得

### 2️⃣ **渐进式引导**
- 未选择：显示引导界面
- 选择后：立即切换到对应操作界面
- 生成后：实时预览在右侧

### 3️⃣ **情感化设计**
- AI助手有头像、名字（小慧）
- 对话式交互，不是冰冷的表单
- 彩色渐变背景，愉悦的视觉体验
